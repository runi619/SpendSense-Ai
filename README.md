SpendSense AI — Expense Auditor & Anomaly Hunter

Track: Finance & Risk
Team: NeuroNova
Event: AgentX Challenge 2026

Overview

SpendSense AI is an autonomous AI-powered financial auditing agent that analyzes transaction data, detects suspicious spending patterns, and generates personalized budget recommendations.

Problem

Individuals often struggle to identify duplicate payments, unusual expenses, recurring subscriptions, and unexpected spending patterns in their financial records.

Proposed Solution

SpendSense AI uses an AI agent with specialized Python tools to investigate financial transactions, identify potential anomalies, explain its findings, and recommend budget improvements.

Key Features

- Transaction categorization
- Duplicate payment detection
- Unusual spending detection
- Recurring subscription identification
- Explainable financial reports
- Personalized budget recommendations

Agent Architecture

The agent follows a genuine autonomous workflow:

Thought → Action → Observation → Decision

It selects appropriate tools, examines their outputs, and decides the next step based on the observations.

Technology Stack

- Python
- Google Gemini API
- Pandas
- Streamlit
- GitHub

Project Status

Development in progress for AgentX Challenge 2026.

Dataset

The project will use the transaction dataset provided for the Finance & Risk challenge.
