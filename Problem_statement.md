SpendSense AI — Expense Auditor & Anomaly Hunter

Track

Finance & Risk

Problem Statement

Individuals often struggle to manage their finances because transaction records contain duplicate payments, recurring subscriptions, unusual spending patterns, and unexpected expenses that are difficult to identify manually.

SpendSense AI is an autonomous AI agent designed to analyze financial transaction data, identify potential anomalies, investigate suspicious spending patterns using specialized tools, and generate personalized budget recommendations.

Key Features

- Automatic transaction categorization
- Duplicate transaction detection
- Unusual spending detection
- Recurring subscription identification
- Explainable anomaly reports
- Personalized budget recommendations

Agent Workflow

Thought → Action → Observation → Decision

The agent dynamically selects appropriate tools, observes their outputs, and determines the next action before generating its final financial report.

Technology Stack

- Pandas
